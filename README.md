# MaiMei 💄 — Персональный гид по косметике

**MaiMei** — это интеллектуальный каталог косметических продуктов, который помогает пользователям ориентироваться в мире бьюти-индустрии. В отличие от обычных магазинов, приложение не продает товары, а формирует персональную ленту рекомендаций на основе профиля и предпочтений пользователя, выявленных в ходе опроса.

* **Ссылка на сайт** [https://pr0stSasha.github.io/cosmetics-app/](https://pr0stSasha.github.io/cosmetics-app/)
* **Проект** [https://pr0stsasha.github.io/Frontend_second_sem/](https://pr0stsasha.github.io/Frontend_second_sem/)

---

## 🛠 Технологический стек

* **Frontend:** React + TypeScript + Vite.
* **State Management:** Redux Toolkit.
* **Backend-as-a-Service:** Supabase (Auth, Database).
* **AI Integration:** Автоматизация описаний продуктов для администраторов.

## 🚀 Быстрый старт

### 1. Получение исходников

```bash
git clone https://github.com/pr0stSasha/cosmetics-app.git
cd cosmetics-app/cosmetics-app

```

### 2. Требования

* **Node.js:** версия 18.x или выше (LTS рекомендуется).
* **npm:** поставляется вместе с Node.js.
* **Supabase Project:** Активный проект для работы API.

### 3. Установка и запуск

1. **Установите зависимости:**
```bash
npm install

```


2. **Настройте окружение:**
Создайте файл `.env` в корне проекта и добавьте ключи доступа из панели Supabase и Groq:
```env
VITE_SUPABASE_URL=project_url_here
VITE_SUPABASE_ANON_KEY=your_anon_key_here
VITE_GROQ_API_KEY=your_groq_key

```


3. **Запустите сервер разработки:**
```bash
npm run dev

```


Приложение откроется по адресу: `http://localhost:5173`

## 🧬 Основной сценарий использования

### Для пользователя:

1. **Прохождение опроса:** Укажите параметры своей кожи и предпочтения в профиле.
2. **Персональная лента:** На главной странице отобразятся только те продукты из интернета, которые подходят именно вам.
3. **Избранное:** Сохраняйте понравившиеся находки в личную коллекцию для быстрого доступа.

### Для администратора:

1. **Наполнение каталога:** Добавление новых продуктов вручную или с помощью ИИ (автогенерация описаний по названию).
2. **Управление актуальностью:** Редактирование характеристик и удаление устаревших позиций через удобный интерфейс карточек.

---

### Основной бизнес-кейс приложения

1. Пользователь заходит на сайт
2. Проходит опрос о типе кожи и предпочтениях
3. Приложение получает персональные рекомендации косметических средств
4. Пользователь может:
   - просматривать карточки товаров
   - добавлять товары в избранное
   - искать продукты по параметрам

Цель приложения — помочь пользователю быстрее подобрать подходящую косметику
на основе персональных данных.
